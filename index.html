Unpin your tools from your distro

Universal Package Installer

Use the unpin command to manage your tools globally across any Linux, macOS, or Windows environment.

Zero Dependencies

Stop waiting on your distro. unpin install drops each tool in PATH ready to run — no system dependencies, no root.

GitHub Native

Pulls each package straight from its GitHub release page. Leverages the infrastructure you already trust.

Pre-compiled Binaries

A curated set of ready-to-install binaries, built reproducibly with Nix.

Usage Examples

Install standard tools like htop:

unpin install htop htop # Ready to run!

Or install specific tools directly from their GitHub repositories, such as jgm/pandoc:

unpin install jgm/pandoc pandoc --version

Just need something once? Use run to fetch and execute it without installing into PATH:

unpin run tree

Installation

Linux
mkdir -p ~/.local/bin curl -sLo ~/.local/bin/unpin "https://unpins.org/unpin-$(uname -m)-linux" chmod +x ~/.local/bin/unpin

Ensure ~/.local/bin is in your PATH.

macOS
mkdir -p ~/.local/bin curl -sLo ~/.local/bin/unpin "https://unpins.org/unpin-$(uname -m)-darwin" chmod +x ~/.local/bin/unpin

Ensure ~/.local/bin is in your PATH.

Windows
$DEST="$env:LOCALAPPDATA\unpin" mkdir $DEST -Force > $null irm https://unpins.org/unpin-x86_64-windows.exe -OutFile "$DEST\unpin.exe"

Ensure %LOCALAPPDATA%\unpin is in your PATH.

About

unpins publishes portable, statically-linked builds of essential command-line tools — the same artifact runs on Debian, Alpine, macOS, and (where viable) Windows. Each build is reproducible with Nix Flakes: inputs are pinned, the output is auditable, and the recipe lives in a public flake you can rebuild yourself.

The project is split across small, focused repos:

  • unpin — the CLI that fetches a binary from GitHub releases and drops it in PATH.
  • One repo per packaged tool — one flake, one binary.
  • nix-lib and action-build — shared build helpers used by the package repos.

Everything lives under github.com/unpins.
